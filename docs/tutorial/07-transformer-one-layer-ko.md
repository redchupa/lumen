# 7장. Transformer 한 layer를 통과하면 무슨 일이 일어나나

> 이 장에서는 LLM 모델의 핵심 구조인 **Transformer**의 한 layer 안에서 정확히
> 어떤 계산이 일어나는지 다룹니다. 1장에서 "표 24장(layer) 통과"라고 풀었던 그
> "표 한 장"의 내부 동작이에요. attention, RMSNorm, RoPE, SiLU 같은 단어들이
> 등장하는데, "회의실 5명이 발언하고 정리하는 과정" 비유로 풀어 갑니다. 이 장이
> 끝나면 GitHub에서 transformer 코드를 봤을 때 "어디서 무엇이 일어나는지" 보입니다.

## 7.1 Transformer가 뭐였더라

먼저 큰 그림 잡기. **Transformer**는 2017년 구글 논문에서 처음 소개된 신경망 구조
인데, ChatGPT, GPT-4, Claude, Llama, Qwen, 거의 모든 현대 LLM이 이 구조를 씁니다.
한 글에서 다 풀기는 어려운 큰 주제라 이 책에서는 **추론 시점의 한 layer 동작**에만
집중합니다.

Transformer 모델 전체는 layer가 여러 개 쌓인 구조예요. Qwen2.5-0.5B는 24개,
GPT-4는 약 120개로 추정됩니다. 모든 layer가 거의 같은 구조예요. 한 layer를
이해하면 전체를 이해한 셈입니다.

한 layer를 한 줄로 풀면 이렇습니다.

> 입력 벡터를 받아서, "주변 단어와 관계 보기"(attention)와 "비선형 변환"(FFN)을
> 차례로 적용해서 출력 벡터를 만든다.

이걸 더 풀어서 8단계로 쪼개 봅니다.

## 7.2 한 layer 통과의 8단계

각 단계가 무엇이고 왜 필요한지 순서대로 봅니다. 입력은 1장에서 본 그 896개 실수
벡터예요.

```
1. 입력 정규화 (attention RMSNorm)
2. Q/K/V 매트멀 — 입력을 세 가지 다른 시각으로 변환
3. RoPE — 위치 정보 추가
4. Attention — 주변 단어와 관계 계산
5. 출력 매트멀 (wo)
6. Residual + 다음 정규화 (FFN RMSNorm)
7. Gate/Up 매트멀 + SiLU 활성화
8. Down 매트멀 + Residual
```

8단계지만 진짜 무거운 건 매트멀이 들어 있는 2, 5, 7, 8단계예요. 나머지(1, 3, 4,
6)는 시간 비중 작습니다. 1장에서 매트멀 95% 차지한다는 게 여기서 다시 확인돼요.

## 7.3 RMSNorm — 입력 정규화

첫 단계는 **RMSNorm**입니다. 이름이 어려워 보이지만 한 줄로 풀면 "벡터의 크기를
일정하게 맞추는 것"이에요.

왜 필요할까요? LLM 모델에서 입력 벡터의 값들이 layer를 통과할수록 점점 커지거나
점점 작아지는 경향이 있어요. 이걸 그대로 두면 값들이 무한대로 커지거나 0으로
수렴해서 계산이 불안정해집니다. 그래서 매 layer 시작에 "벡터 크기를 일정 범위로
다시 맞춰주는" 단계가 필요해요.

RMS는 Root Mean Square의 약자. 벡터의 평균 제곱근입니다.

```
입력 벡터: [a1, a2, ..., a896]
rms = sqrt((a1^2 + a2^2 + ... + a896^2) / 896)
출력 벡터: [a1/rms * w1, a2/rms * w2, ..., a896/rms * w896]
```

각 원소를 RMS로 나누고, 학습된 weight를 곱해요. 이 과정으로 출력 벡터의 RMS는
대략 1 수준이 됩니다. 정확히 1은 아니고 weight에 따라 조절됨.

### 왜 LayerNorm이 아닌 RMSNorm인가

이전 세대 LLM(GPT-2 등)은 **LayerNorm**을 썼어요. RMSNorm과 비슷한데 평균도 빼주는
단계가 있습니다. 더 복잡한 만큼 살짝 더 좋은 정규화 효과가 있긴 한데, 추가 계산
비용이 들어요.

RMSNorm은 LayerNorm에서 평균 빼는 단계를 제거한 단순 버전입니다. 실험적으로 답
품질은 거의 동일한데 계산이 약 20% 빠르고요. Llama 이후로 거의 모든 현대 LLM이
RMSNorm으로 갔어요.

이 단계는 시간 비중이 작습니다. 매트멀의 1% 정도. 직접 짤 때는 한 줄짜리 loop으로
충분히 빨라요. SIMD 굳이 안 써도 됩니다.

## 7.4 Q/K/V 매트멀 — 세 가지 다른 시각으로 변환

이제 본격 매트멀이 시작됩니다. 입력 벡터(896개 실수)를 **세 개의 다른 벡터로 변환**
해요. Q, K, V라고 부릅니다.

- **Q (Query)**: "내가 무엇을 찾고 싶은가" 표현
- **K (Key)**: "내가 어떤 정보를 가지고 있는가" 표현
- **V (Value)**: "내가 제공할 수 있는 실제 정보" 표현

이 셋은 같은 입력에서 변환되지만 각각 다른 weight 행렬을 곱해서 만들어요. 그래서
같은 데이터를 세 가지 "관점"으로 보는 셈입니다.

```
Q = input × W_q       (W_q: 896 × 896)
K = input × W_k       (W_k: 896 × 128)
V = input × W_v       (W_v: 896 × 128)
```

각 매트멀은 1장에서 본 그 매트멀이에요. 합쳐서 매트멀 3번이 일어납니다. 실제로는
세 weight를 합쳐 한 매트멀(896 × 1152)로 처리하는 게 더 효율적이에요. Lumen도
이렇게 합쳐서 한 번에 처리합니다. 이걸 "QKV matmul"이라고 부릅니다.

### Q와 KV의 크기가 다른 이유 — GQA

Qwen2.5-0.5B는 Q가 896 차원인데 K, V는 128 차원. 왜 다를까요? 이건 **GQA (Grouped
Query Attention)**라는 변형입니다.

원래 transformer는 Q, K, V가 다 같은 크기였어요(MHA: Multi-Head Attention). 그런데
KV가 메모리를 많이 차지해서, KV 크기를 줄이고 Q만 크게 유지하는 변형이 나왔습
니다(GQA). 답 품질 거의 같은데 메모리 절약 큼.

Qwen2.5의 경우 Q는 14개 head(각 64 차원, 합 896), K/V는 2개 head(각 64 차원, 합
128). Q 14개가 K/V 2개를 공유하는 형태. 7개 Q head가 같은 K/V를 보는 거예요.

이 디테일은 attention 동작 이해할 때 다시 나옵니다. 일단 "Q가 큰 게 정상, KV가
작은 게 GQA 변형"만 기억해 두세요.

## 7.5 RoPE — 위치 정보 추가

다음 단계는 **RoPE (Rotary Position Embedding)**. 한 줄로 풀면 "벡터에 위치 정보를
넣는 것"이에요.

문제: Q와 K 벡터는 매트멀로 만들어졌는데, 매트멀은 입력 단어의 **순서**를 모릅
니다. "나는 학교에 갔다"와 "학교에 갔다 나는"이 같은 단어인데 순서만 다른 문장은,
같은 입력 벡터들을 받으면 같은 결과를 만들어요. 그런데 두 문장은 의미가 다르
잖아요. 위치를 모델에 알려줘야 합니다.

RoPE는 이 위치를 **벡터를 회전시키는 방식**으로 인코딩해요. 벡터를 2차원씩 묶어서
position에 따라 다른 각도로 회전시킵니다.

```
position 0인 벡터: 회전 0도
position 1인 벡터: 회전 1도 (또는 다른 작은 각도)
position 2인 벡터: 회전 2도
...
position N인 벡터: 회전 N도
```

같은 단어 "학교"여도 0번째 자리에 있는지 5번째 자리에 있는지에 따라 벡터가
다르게 회전돼요. 그러면 attention 단계에서 두 단어를 비교할 때 위치 정보까지
함께 비교됩니다.

이 단계는 시간 비중 매우 작아요(1% 미만). 단순한 sin/cos 계산이라 SIMD로 쉽게
처리 가능. Lumen에서는 위치별 회전값을 미리 계산해 두고 통과 시점에 그대로
적용합니다(precompute optimization).

## 7.6 Attention — 회의실 5명이 발언하기

이제 핵심 단계 **Attention**입니다. 한 문장의 모든 단어가 서로 "관계"를 보는
단계예요.

### 회의실 비유

5명이 회의실에 모여 있다고 합시다. 각자 발언 주제(Query), 자기가 가진 정보
(Key), 발언 내용(Value)이 있어요. 회의 진행 방식:

1. 한 사람(예: 3번째 사람)이 자기 Query를 가지고 "내가 알고 싶은 게 이건데, 다른
   사람들 중에 누가 관련 있을까?"라고 묻습니다.
2. 다른 사람들 각자 자기 Key를 그 Query와 비교해서 "내 정보가 얼마나 관련 있는가"
   점수 매김.
3. 관련 있는 사람일수록 그 사람의 Value(발언 내용)를 더 많이 들음. 점수 비례.
4. 모든 발언을 가중치 합산해서 3번째 사람의 새 정보 만들기.

이게 attention의 기본 동작이에요. 한 단어가 다른 모든 단어를 보면서 "각 단어가
얼마나 관련 있나"를 점수 매기고, 점수에 비례해서 정보를 가져옵니다.

### 수학적 표현

```
attention(Q, K, V) = softmax(Q × K^T / sqrt(d)) × V
```

- `Q × K^T`: 각 Q와 각 K의 dot product (관련도 점수)
- `/ sqrt(d)`: 정규화 (점수가 너무 커지지 않게)
- `softmax(...)`: 점수를 확률 분포로 변환 (합이 1)
- `× V`: 점수 가중 평균으로 V 합산

수학 표기가 복잡해 보이지만 회의실 비유의 정확한 표현입니다. Q와 K로 점수 만들고,
점수 비례로 V 합산.

### Causal mask — 미래 단어는 안 봄

LLM은 답을 한 단어씩 만들 때 **아직 만들지 않은 미래 단어**를 보면 안 됩니다.
그래서 한 단어가 attention할 때 **자기보다 뒤에 있는 단어는 점수를 0으로 강제**
해요. 이걸 causal mask라고 부릅니다.

```
"나는 학교에 갔다"의 attention 매트릭스:

       나는  학교에  갔다
나는    1    -∞     -∞     ← "나는"은 자기만 봄
학교에  1     1     -∞     ← "학교에"는 자기와 이전 단어만
갔다    1     1      1     ← "갔다"는 모든 단어
```

-∞ 자리는 softmax 통과 후 0이 됩니다. 이게 LLM이 답을 "왼쪽에서 오른쪽으로"
하나씩 만들 수 있는 이유예요.

### KV cache — 같은 K, V를 매번 안 계산함

답을 한 단어씩 만들 때마다 매 단어의 K, V를 다시 계산하면 낭비입니다. 이미 만든
단어들의 K, V는 한 번만 계산하고 메모리에 저장해 두면 돼요.

이걸 **KV cache**라고 부릅니다.

```
1번째 단어 만들 때: K1, V1 계산하고 캐시 저장
2번째 단어 만들 때: K2, V2 계산. 1번째의 K1, V1은 캐시에서 가져옴
3번째 단어 만들 때: K3, V3 계산. K1~K2, V1~V2는 캐시에서
...
```

이 덕분에 답 만들 때마다 새로 계산하는 건 마지막 한 단어 분량만이에요. 그래서
decode가 가능한 속도로 동작합니다(1장의 그 매트멀 3840번).

prefill에서는 입력 단어 전체의 K, V를 한 번에 계산해서 캐시에 저장합니다.

### Attention의 시간 비중

attention은 매트멀 5개에 비하면 작아요. Lumen 측정 기준 한 layer의 attention은
약 3%, 매트멀 5개 합계 91%, 나머지 6%. 그래서 attention 자체보다 매트멀 최적화가
더 큰 효과예요.

다만 attention은 **시퀀스 길이의 제곱**으로 비용이 늘어납니다. 단어 32개 처리면
32² = 1024번 점수 계산, 단어 256개면 65536번. 긴 컨텍스트(예: 32K 단어)에서는
attention이 매트멀보다 훨씬 큰 비중이 됩니다. 그래서 **flash attention** 같은
가속 기법이 발달했어요. 이 책에서는 다루지 않지만 "긴 컨텍스트면 attention이
병목"이라는 사실만 기억해 두세요.

## 7.7 Output projection (wo) — 매트멀 한 번 더

attention 결과는 다시 매트멀 한 번 더 통과해야 layer 출력이 됩니다. 이걸
**output projection** 또는 **wo (W output)**라고 불러요.

```
attention_out = wo_matmul(attention_result, W_o)
W_o: 896 × 896
```

attention의 결과를 다시 hidden 차원(896)으로 정리하는 단계. 매트멀 한 번이라 시간
비중 약 6%.

## 7.8 Residual + FFN RMSNorm

attention 단계 끝나면 결과를 입력에 더해요. 이걸 **residual connection**이라고
합니다.

```
intermediate = input + attention_out
```

왜 이렇게 하나요? 정보 손실 방지. 매 layer마다 input이 새 출력으로 완전히 대체
되면 layer를 많이 쌓을수록 원래 정보가 사라집니다. residual로 원래 input을
다음 단계로 그대로 전달해서 깊은 모델도 학습 가능하게 해요.

그 다음 또 한 번 정규화 단계가 있어요(FFN RMSNorm). 7.3절의 RMSNorm과 같은 동작.

## 7.9 FFN — Gate/Up + SiLU + Down

다음은 **FFN (Feed-Forward Network)**. 비선형 변환 단계예요.

attention만으로는 단순한 가중 평균이라 모델이 표현할 수 있는 패턴이 제한적
입니다. FFN이 비선형성을 추가해서 모델이 복잡한 패턴을 표현할 수 있게 해요.

FFN 구조:

```
gate = ffn_in × W_gate      (896 → 4864)
up   = ffn_in × W_up        (896 → 4864)
mid  = silu(gate) * up      (element-wise)
out  = mid × W_down         (4864 → 896)
```

세 매트멀(gate, up, down)과 SiLU 활성화 함수.

### SiLU 활성화

**SiLU(Sigmoid-weighted Linear Unit)**는 비선형 함수입니다. 수식:

```
silu(x) = x * sigmoid(x) = x / (1 + e^(-x))
```

복잡해 보이지만 효과는 단순해요. 양수는 거의 그대로 통과, 음수는 0에 가깝게 만들
어버림. 이 비선형 처리가 모델의 표현력 핵심.

### gate * up 곱셈

`silu(gate) * up`이 SwiGLU라는 변형. 단순 ReLU/SiLU만 쓰는 것보다 답 품질이 약간
좋다는 측정이 있어서 Llama 이후 거의 표준이 됐어요.

이 단계의 시간 비중이 크다는 사실. FFN 매트멀 3개(gate, up, down)가 attention보다
훨씬 큰 비중이에요. Qwen2.5-0.5B 측정 기준:

- gate + up (합쳐서 한 매트멀로 처리): 40%
- down: 21%
- qkv: 8%
- wo: 6%
- attention + 작은 op들: 25% (이 중 매트멀 외는 6%)

FFN 매트멀 두 개(gate/up + down)가 한 layer 시간의 61%. 매트멀 최적화는 FFN 부분이
가장 큰 효과예요.

## 7.10 한 layer 통과 전체 정리

여기까지 본 8단계를 다시 정리하면 이렇습니다.

```
입력 벡터 (hidden=896 차원)
  │
  ├── 1. attention RMSNorm        ← 정규화 (작음)
  ├── 2. QKV 매트멀                ← 큰 매트멀 1개
  ├── 3. RoPE                      ← 위치 정보 추가 (작음)
  ├── 4. Attention                 ← Q, K, V 조합 (중간)
  ├── 5. wo 매트멀                  ← 큰 매트멀 1개
  ├── 6. Residual + FFN RMSNorm    ← 합치기 + 정규화 (작음)
  ├── 7. Gate/Up + SiLU            ← 큰 매트멀 2개 + 활성화
  └── 8. Down + Residual           ← 큰 매트멀 1개 + 합치기
  │
  ▼ 다음 layer로 전달
```

매트멀 5개(QKV, wo, gate, up, down)가 시간의 약 95%. 나머지(RMSNorm, RoPE,
attention, residual, SiLU)가 약 5%.

이 패턴이 layer 24개(Qwen2.5-0.5B 기준)에 똑같이 적용돼요. 같은 구조의 layer가
24번 반복되는 거예요. 마지막 layer의 출력이 다시 한 번 RMSNorm 통과 후
**lm_head 매트멀**로 어휘 사전 크기(151936)로 확장됩니다. 그게 1장에서 본 "점수
배열"이고, 가장 높은 점수의 단어가 다음 단어예요.

## 7.11 7장 핵심 정리

1. **한 layer = 8 단계 통과**. 매트멀 5개(QKV, wo, gate, up, down)가 시간의 95%.
   나머지는 정규화/위치/attention/residual로 합쳐서 5%.

2. **Q/K/V는 같은 입력을 세 가지 시각으로 변환**. Q는 찾고 싶은 것, K는 가진 정보,
   V는 실제 내용. 매트멀 3개로 만들고 한 매트멀로 합칠 수도 있음.

3. **RoPE는 벡터를 회전시켜 위치 정보 인코딩**. 같은 단어라도 위치에 따라 다르게
   회전. 시간 비중 작음.

4. **Attention은 회의실 비유**. Q와 K로 점수 만들고 점수 비례로 V 합산.
   causal mask로 미래 단어 차단. KV cache로 이전 단어 K/V 재계산 안 함.

5. **FFN(gate/up/down + SiLU)이 매트멀 시간의 60%+**. attention보다 훨씬 큰 비중.
   매트멀 최적화는 FFN이 ROI 최대.

빨라야 하는데 실제로는 1.5~2배만 빨라지는 이유. "8명이 한 우물에서 물 긷기" 비유로
메모리 대역폭 한계가 어떻게 작동하는지 풀어 봅니다. 그리고 ThreadPool이 어떻게
worker들에게 task를 분배하는지, atomic counter 패턴이 mutex 패턴보다 빠른 이유도
같이 봅니다.
